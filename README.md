# Dynamic Quiz Application

This project is a Dynamic Quiz Application built using HTML, CSS, and JavaScript.

## Features
- Category selection (Web Development / Software Testing)
- Difficulty levels (Easy, Medium, Hard)
- Dynamic loading of quiz questions
- Countdown timer for each question
- Automatic navigation when timer ends
- Result analysis showing correct and incorrect answers
- Visual result analysis using charts
- Responsive user interface

## Technologies Used
- HTML
- CSS
- JavaScript
- Chart.js

## Automation Testing
This application is designed to be automated using Selenium WebDriver for UI testing and validation.
